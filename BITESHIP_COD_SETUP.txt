SUBUR MUJUR TANI — Biteship COD

PENTING:
Semua nilai rahasia harus disimpan hanya di Netlify Environment Variables.
Jangan menaruh API key, service-account JSON, webhook secret, nomor telepon,
alamat lengkap, atau nilai rahasia lain di source code/repository.

Environment Variables yang diperlukan:
- BITESHIP_API_KEY
- BITESHIP_ORIGIN_POSTAL_CODE
- BITESHIP_ORIGIN_CONTACT_NAME
- BITESHIP_ORIGIN_CONTACT_PHONE
- BITESHIP_ORIGIN_CONTACT_EMAIL
- BITESHIP_ORIGIN_ADDRESS
- BITESHIP_ORIGIN_ORGANIZATION
- BITESHIP_COD_TYPE
- FIREBASE_SERVICE_ACCOUNT_JSON
- FIREBASE_DATABASE_URL
- BITESHIP_WEBHOOK_SIGNATURE_KEY
- BITESHIP_WEBHOOK_SIGNATURE_SECRET
- BITESHIP_ADMIN_EMAILS (opsional)

Isi nilai-nilai di atas langsung melalui Netlify > Site configuration >
Environment variables. Jangan menyalin nilainya ke file ini.

BITESHIP_COD_TYPE harus diisi dengan salah satu pilihan yang didukung akun
Biteship Anda. Gunakan nilai yang Anda pilih di Netlify.

Webhook:
https://DOMAIN-ANDA/.netlify/functions/biteship-webhook

Alur COD aplikasi:
Menunggu Konfirmasi COD
-> Dikemas
-> Buat Pengiriman
-> Resi
-> Dikirim
-> COD Lunas

Webhook Biteship hanya memperbarui data pengiriman/resi dan informasi teknis.
Webhook tidak boleh melompati status toko.

Mode testing Biteship dapat digunakan saat pengujian.
